#  Menu Interativo

> Uma aplicação web de menu interativo desenvolvida para facilitar a visualização de itens, navegação fluida por categorias e experiência de cardápio digital moderno.

---

## 🔗 Acesse o Projeto Online
Teste a aplicação funcionando em tempo real:
- **[🔗 Ver Menu Interativo na Vercel](https://menu-interativo-lime.vercel.app)**

---

## 🛠️ Tecnologias Utilizadas
- **HTML5**: Estruturação semântica do cardápio e seções.
- **CSS3**: Estilização visual, design responsivo e organização dos elementos.
- **JavaScript (ES6+)**: Lógica de interatividade, manipulação do DOM e dinamismo da interface.

---

## ✨ Funcionalidades
- **Navegação Intuitiva**: Organização clara de produtos ou categorias no cardápio.
- **Design Responsivo**: Adaptado para visualização perfeita tanto em telemóveis quanto em computadores.
- **Interface Dinâmica**: Resposta visual rápida às interações do utilizador na página.
